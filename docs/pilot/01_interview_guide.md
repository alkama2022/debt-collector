# CollectNaija — Phase 0 Interview Guide (45 min)

## Goal (§4)
Recruit 10 pilot orgs. Kill fiction before code. Prove: problem intensity, channel fit, willingness-to-pay, data readiness.

## Recruit (20-30 orgs, 5 verticals)
- Private schools (nursery/primary) — Lagos + Ibadan
- Clinics/pharmacies
- Trade/retail distributors
- Services (agencies, tutors)
- Cooperatives (non-regulated)

Criteria: 30-1,000 active customers, invoices monthly, WhatsApp used to chase, owner available 30m/week.

## Script
1. **Intro (2m):** "We help businesses know who owes what and follow up respectfully via WhatsApp. Not a loan collector. 45m, we’ll photo your current tracking (with permission)."
2. **Current state (10m):** Show notebook/Excel/WhatsApp. Ask: How do you track? Who tracks? How many outstanding now? % overdue >7/30d? How many hours/week chasing?
3. **Walk last 5 collections (15m):** For each: amount, due date, channel used, how many reminders, what happened, dispute? Note tone, time spent, failure modes.
4. **Pain (5m):** Biggest leak? Forgotten debts last month estimate? Screenshot disputes? Staff turnover loss?
5. **Willingness-to-pay (10m):** Van Westendorp — At what price is it too cheap/too expensive? "Would you pay ₦5k/12k/25k today for X?" Test Free→Starter→Business cards. Note anchor.
6. **Pilot test (3m):** "If we import your 20 customers/invoices this week and handle reminders via WhatsApp, would you trial 4 weeks, 30m/week feedback, refer 1 if it works?" Yes/Maybe/No + barrier.

## Photo artifacts
- Notebook/sheet (redact PII)
- WhatsApp thread (with consent)

## Close
"Thank you — we’ll share anonymized findings. If pilot-ready, we’ll contact within 48h to import."

## Success gate (§4)
≥12 pilot-ready (active receivables, WhatsApp reachable ≥60%, can provide list in 48h). Else narrow ICP to schools.
